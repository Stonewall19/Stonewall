# StoneWall WordPress Marketplace Plugin

## Installation Instructions

1. Download the plugin zip file from the official repository.
2. Go to your WordPress admin panel.
3. Navigate to `Plugins` > `Add New` > `Upload Plugin`.
4. Choose the downloaded zip file and click `Install Now`.
5. Once installed, click `Activate` to enable the plugin.

## Features
- User-friendly interface for both buyers and sellers.
- Secure payment integration.
- Real-time notifications for marketplace activities.
- Various customization options for plugin settings.
- Comprehensive documentation and support.

## Setup Guide

1. After activating the plugin, navigate to the `StoneWall` menu in your WordPress dashboard.
2. Configure the settings as per your marketplace requirements.
3. Add marketplace categories and products.
4. Set up payment gateways for transactions.
5. Invite users to register as buyers or sellers.

For additional support and updates, please refer to the official documentation or GitHub repository.
